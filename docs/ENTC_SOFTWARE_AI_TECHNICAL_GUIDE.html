1. Software Architecture Overview (At a Glance)

The Smart Pesticide Residue Detection System runs as a fully autonomous embedded instrument. The entire software stack—including digital image preprocessing, deep convolutional neural network inference, multi-sensor analog conversion, and 5-page OLED reporting—runs 100% locally on the STM32F407VET6 microcontroller. It requires zero internet, zero cloud connection, and zero laptop dependency during execution.

3. Model Training, Dataset & INT8 Quantization Process

  • Training Corpus: Model 1 was trained on 8,457 real, verified produce images aggregated from 3 benchmark agricultural datasets: FruitNet (Indian market produce), AgriFreshNET, and Mendeley Produce Quality.
  • Zero Data Leakage: Training, validation, and test sets were partitioned strictly by acquisition sessions. Images taken in the same lighting batch never overlapped between training and testing.
  • Data Augmentation: Random rotations, center crops, brightness shifts, and color jitter were applied to ensure model robustness under varying classroom/laboratory lighting.
  • Post-Training Quantization (PTQ): Floating-point 32-bit weights were converted to 8-bit signed integers (int8) using TensorFlow Lite converter. Formula: q = round(x / Scale) + ZeroPoint. This reduced model memory by 4x (from ~1.5 MB down to ~370 KB) with < 0.4% drop in accuracy.
  • ARM CMSIS-NN Optimization: Cortex-M4 DSP SIMD assembly executes 4 multiply-accumulate operations in a single clock cycle, completing inference in ~120 ms.

4. Microcontroller Memory Layout (Zero-Heap Architecture)

In embedded systems, dynamic heap allocation (malloc/free) causes memory fragmentation and sudden crashes. The firmware uses 100% static compile-time memory budgeting (STM32F407VETX_FV.ld):

Memory Region Physical Base Assigned Functions Used Bytes Total Available Safety Margin
FLASH ROM 0x08000000 Firmware code (.text), Vector Table, TFLM INT8 Model Weights (.rodata) 442,932 B 512 KB 84.5% (69 KB Free)
SRAM1 0x20000000 Camera DMA double buffer (38.4 KB), system stack, application variables 127,456 B 128 KB 97.2% (100% Static)
CCMRAM 0x10000000 TFLM Persistent Tensor Activation Arena (Core Coupled Memory, zero bus wait) 53,248 B 64 KB 81.2% (11 KB Free)

6. Top 5 Viva Questions & Answers (ENTC Examination Cheat Sheet)

Q1: Which Machine Learning model did you use for image classification and why?
Answer: "We deployed a multi-task MobileNet Convolutional Neural Network (CNN) quantized to INT8, executing via TensorFlow Lite for Microcontrollers (TFLM). MobileNet utilizes depthwise-separable convolutions, reducing parameters and computation by ~85% compared to standard CNNs, allowing full vision inference within the STM32's 512KB Flash."
Q2: How can a heavy neural network run on an STM32 with only 512KB Flash and 192KB RAM?
Answer: "Through Post-Training Quantization (PTQ), converting 32-bit floating-point weights into 8-bit signed integers (INT8). This compressed the model by 4x (down to ~370 KB) without sacrificing accuracy. In addition, ARM CMSIS-NN SIMD kernels leverage Cortex-M4 DSP instructions to perform 4 multiply-accumulates per cycle, achieving ~120 ms latency."
Q3: How does the system detect pesticide residues using hardware sensors?
Answer: "We employ Multi-Sensor Data Fusion across three complementary physical channels: (1) Surface chlorophyll reflectance ratio (G/R) via TCS34725 optical colorimeter, (2) Volatile organic vapor emissions via MQ135 gas sensor, and (3) Electro-chemical wash-water acidification via analog pH glass probe (as commercial organophosphates hydrolyze into acidic ions). Model 2 fuses these signals into a unified risk score."
Q4: How is shelf life calculated? Is it a hardcoded static value?
Answer: "No, shelf life is 100% dynamic. It is computed in real time using the mathematical formula: Estimated_Days = Base_Days × Visual_Freshness - Ambient_Temperature_Penalty. The DHT22 sensor monitors real-time room temperature; higher ambient temperatures accelerate post-harvest respiration, reducing the displayed shelf life dynamically."
Q5: What happens when no fruit is placed on the scanning tray?
Answer: "The system features a dual-stage optical presence gate. When the tray is empty, unobstructed room light hits the TCS34725 sensor (lux > 4800) and camera texture variance drops below 350.0. The system automatically enters Standby Mode, alternating every 5 seconds between college project credits and the 'Place Fruit on Tray' prompt."
